# Orca 插件验证

- `npm test`：10 项模拟 CLI 测试通过，覆盖项目添加/复用、原文参数、接收阶段、未就绪、未知创建/发送、重复请求、失效终端、后续消息和显式终端选择。
- 插件无运行依赖；入口为 Node ESM，不需要构建或 npm 安装。
- 在 Asky 的原生插件页实际从 GitHub 安装，官方类型、版本与 Git commit 正确显示；配置、停用、卸载回读通过。
- 在独立测试 Git 仓库中，通过 Asky ToolService 创建独立 worktree、启动 Codex、提交测试 prompt、查询状态和提交后续消息。约 23 秒通过，提交与后续消息均得到 turn_started 回执；此结果不等于任意开发任务已完成。
- 首次真实验收发现回执嵌套于 send.prompt；修复后重新从 GitHub 安装并重跑通过。显式终端选择为后续补充接口，已通过模拟测试。
- 原始日志包含本机路径，留在主应用忽略的 build 目录，不公开。未修改用户的真实项目。
